# Panther Parking Predictor

A model and a tiny web app that predict how full each FIU garage will be at the time you arrive, trained on a year of gate counts.

An INIT Studio project at INIT at FIU. Its page on INIT: https://dev.init.plus/build/p/cd3299ae-946c-4d03-8df8-5f7c20c02d98
